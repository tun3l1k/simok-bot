# SimOk (Telegram Mini App)

Крутишь SIM-карты с номерами разной редкости, сохраняешь лучшие в коллекцию, остальное продаётся. Чем красивее номер («Пара-пара», «Лесенка», «Зеркало»), тем он дороже.

## Структура

```
bot/index.js          Telegram-бот (grammY): /start с кнопкой «Играть», меню-кнопка, учёт игроков
bot/admin.js          админ-меню /admin: статистика, рассылка, новые игроки, топ приглашений
bot/store.js          список игроков бота (data/users.json)
bot/broadcast.js      рассылка с паузой и обработкой блокировок
webapp/               Mini App, чистый HTML/CSS/JS без сборки
  index.html
  css/style.css
  js/config.js        экономика, редкости, ставки, страны, коды городов, операторы, магазин
  js/flags.js         SVG-флаги стран
  js/registry.js      коды и регионы операторов из реестра Россвязи (генерируется)
  js/skins.js         внешний вид SIM каждого оператора (фон, декор, знак)
  js/generator.js     генерация номера, серии, цена, номер с гарантией редкости
  js/game.js          крутка, коллекция, бонусы, уровни
  js/state.js         сохранение (пока localStorage)
  js/ui.js            отрисовка
  js/telegram.js      обёртка над Telegram WebApp
  js/main.js          связка всего вместе
scripts/simulate.js   проверка экономики (npm run sim)
scripts/smoke-test.js проверка логики без браузера
scripts/admin-test.js проверка админ-меню и рассылки (npm test запускает оба теста)
scripts/build-registry.js собирает registry.js из CSV Россвязи
```

## Перед коммитом

`npm run stamp` ставит новую версию `?v=…` на все js/css. Без этого Telegram на iPhone может показать новый `index.html` со старыми скриптами, и экран разваливается.

## Запуск за 5 минут

1. Создай бота: в Telegram открой @BotFather, команда `/newbot`, сохрани токен.
2. `npm install`
3. Mini App должна открываться по HTTPS. Варианты:
   - выложить папку `webapp/` на GitHub Pages / Netlify / Vercel;
   - или локально: `npm run web` и туннель `cloudflared tunnel --url http://localhost:5173` (или ngrok).
4. `cp .env.example .env`, впиши `BOT_TOKEN` и `WEBAPP_URL` (адрес из шага 3).
5. `npm run bot`, открой бота и нажми «Играть».
6. В `webapp/js/config.js` стоит `BOT_USERNAME: 'SimOkBot'`. Если у бота другой username, поправь его (нужен для ссылок-приглашений).

Игру можно проверить и просто в браузере: `npm run web`, открыть http://localhost:5173.

## Коды регионов

Коды, регионы и веса берутся из реестра Россвязи (`DEF-9xx.csv` с opendata.digital.gov.ru): у каждого оператора свои наборы кодов в каждом регионе, чем больше блоков номеров в регионе, тем чаще он выпадает. Реальные операторы заменены на свои: МТС → МГС, МегаФон → MegaFox, Вымпелком → Билайт, Т2 Мобайл → Теле3, Скартел (Yota) → Йога. Чтобы обновить данные: `npm run registry -- путь/к/DEF-9xx.csv`, потом `npm run stamp`. Город региона и множитель цены задаются в `CITY` (config.js).

## Админ-меню

1. Узнай свой Telegram id (например, у @userinfobot) и впиши в `.env`: `ADMIN_IDS=123456789` (несколько id через запятую).
2. Запусти бота и отправь ему `/admin`. Другим пользователям команда не отвечает.
3. В меню: статистика (игроки, заходы за 24 часа и 7 дней, приглашённые, заблокировавшие бота), рассылка (присылаешь сообщение, смотришь предпросмотр, подтверждаешь; уходит всем, кто не заблокировал бота), новые игроки, топ приглашений.

Игроки записываются в `data/users.json`, когда пишут боту. Прогресс самой игры лежит у игроков на телефоне, поэтому выдать баланс или номер из админки пока нельзя: для этого нужен бэкенд.

## Баланс

`npm run sim` показывает, сколько в среднем стоит номер относительно цены крутки и как часто выпадают серии. Сейчас: обычная крутка отдаёт ~70% цены, с Удачей ~108%.

Там же блок «Ставки»: цена ставки в `BETS` (config.js) должна быть близка к средней цене номера этой редкости. Если поменял редкости, серии или коды городов, пересчитай цены по этому блоку.

## Что уже есть

Крутка 1×/5×/10× (лучший номер остаётся, остальные продаются), номер, который не продал, сам уходит в коллекцию при следующей крутке (в коллекции до 50 номеров, при переполнении продаётся самый дешёвый), продажа выпавшего номера кнопкой «Продать за…», автопродажа слабых номеров в настройках, «Показать друзьям» (красивое сообщение с номером, редкостью и серией), Удача 🍀 (каждые 100 круток заряд x2, каждые 500 круток заряд x20: одна крутка «лучший из N»; клевер в шапке открывает окошко «Гарант удачи»), шторка «Ставка» (дороже крутка — гарантированная редкость, Удача на ней не тратится), выбор оператора в шторке страны (у каждого своя фирменная SIM-карточка; МГС, Йога, MegaFox, Билайт, Теле3: у каждого свои коды, привязанные к макрорегионам (Москва, СЗ, Урал, Сибирь, Дальний Восток, Поволжье, Юг…), без бонусов; большие города выпадают чаще, дальние вроде Магадана и Камчатки редко, зато дороже; «альбом городов» с наградой за полный набор), «Разбор номера» (из чего сложилась цена, «1 из N»), любимая цифра в настройках, слияние 10→1 (гарантия редкости и шанс на редкость выше, доплата, если сумма не дотягивает), шторка выбора страны (играбельна пока Россия, операторы стран появятся позже), «Настройки» во вкладке «Ещё» (автопродажа, любимая цифра), коллекция с продажей, уровни, ежедневный бонус, пособие при нуле, шаринг номера и приглашение друга.

## Что дальше

1. **Бэкенд и база** (Node + Postgres/SQLite). Сейчас прогресс лежит в localStorage, его можно подделать. Крутку, баланс и коллекцию нужно считать на сервере, а клиент должен только показывать. Проверять `initData` от Telegram.
2. **Оплата Stars**: бот создаёт ссылку `createInvoiceLink` (валюта `XTR`), обрабатывает `pre_checkout_query` и `successful_payment`, начисляет товар. Кнопки в магазине уже есть.
3. **Рынок между игроками**: лоты, комиссия 5–10%.
4. **Рефералы**: параметр `ref` уже сохраняется, нужна проверка на сервере и награда.
5. **Другие страны и операторы**, сезонные коллекции, рейтинги, rewarded-реклама.
