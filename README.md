# SimOk (Telegram Mini App)

Крутишь SIM-карты с номерами разной редкости, сохраняешь лучшие в коллекцию, остальное продаётся. Чем красивее номер («Пара-пара», «Лесенка», «Зеркало»), тем он дороже.

## Структура

```
bot/index.js          Telegram-бот (grammY): /start с кнопкой «Играть», меню-кнопка
webapp/               Mini App, чистый HTML/CSS/JS без сборки
  index.html
  css/style.css
  js/config.js        экономика, редкости, ставки, страны, коды городов, операторы, магазин
  js/flags.js         SVG-флаги стран
  js/generator.js     генерация номера, серии, цена, номер с гарантией редкости
  js/game.js          крутка, коллекция, бонусы, уровни
  js/state.js         сохранение (пока localStorage)
  js/ui.js            отрисовка
  js/telegram.js      обёртка над Telegram WebApp
  js/main.js          связка всего вместе
scripts/simulate.js   проверка экономики (npm run sim)
scripts/smoke-test.js проверка логики без браузера
```

## Запуск за 5 минут

1. Создай бота: в Telegram открой @BotFather, команда `/newbot`, сохрани токен.
2. `npm install`
3. Mini App должна открываться по HTTPS. Варианты:
   - выложить папку `webapp/` на GitHub Pages / Netlify / Vercel;
   - или локально: `npm run web` и туннель `cloudflared tunnel --url http://localhost:5173` (или ngrok).
4. `cp .env.example .env`, впиши `BOT_TOKEN` и `WEBAPP_URL` (адрес из шага 3).
5. `npm run bot`, открой бота и нажми «Играть».
6. В `webapp/js/config.js` стоит `BOT_USERNAME: 'SimOkBot'`. Если у бота другой username, поправь его (нужен для ссылок-приглашений).

Игру можно проверить и просто в браузере: `npm run web`, открыть http://localhost:5173.

## Баланс

`npm run sim` показывает, сколько в среднем стоит номер относительно цены крутки и как часто выпадают серии. Сейчас: обычная крутка отдаёт ~70% цены, с Удачей ~108%.

Там же блок «Ставки»: цена ставки в `BETS` (config.js) должна быть близка к средней цене номера этой редкости. Если поменял редкости, серии или коды городов, пересчитай цены по этому блоку.

## Что уже есть

Крутка 1×/5×/10× (лучший номер остаётся, остальные продаются), Удача 🍀 (лучший из 2), шторка «Ставка» (дороже крутка — гарантированная редкость, Удача на ней не тратится), шторка выбора страны (играбельна пока Россия, операторы стран появятся позже), «Настройки» во вкладке «Ещё» (автосохранение редких), коллекция с продажей, уровни, ежедневный бонус, пособие при нуле, шаринг номера и приглашение друга.

## Что дальше

1. **Бэкенд и база** (Node + Postgres/SQLite). Сейчас прогресс лежит в localStorage, его можно подделать. Крутку, баланс и коллекцию нужно считать на сервере, а клиент должен только показывать. Проверять `initData` от Telegram.
2. **Оплата Stars**: бот создаёт ссылку `createInvoiceLink` (валюта `XTR`), обрабатывает `pre_checkout_query` и `successful_payment`, начисляет товар. Кнопки в магазине уже есть.
3. **Рынок между игроками**: лоты, комиссия 5–10%.
4. **Рефералы**: параметр `ref` уже сохраняется, нужна проверка на сервере и награда.
5. **Другие страны и операторы**, сезонные коллекции, рейтинги, rewarded-реклама.
